# Adilo course library → Edufy Academy

**Status (22 Nov 2026):** the import has been run on the live database and verified. The website code still has to be deployed (see Apply order).

| File | What it is |
|---|---|
| `adilo-inventory.raw.json` | The Adilo library as read on 22 Nov 2026 (read-only, through the Edufy API's admin endpoints): projects, video ids, original titles, durations |
| `content.py` | Course content: titles, slugs, SEO title/description, subtitles, descriptions, outcomes, prerequisites, audience, sections with overviews, and every lesson mapped to its Adilo video |
| `build.py` | Validates the content against the inventory and generates the three files below. It stops on any missing, duplicate, mis-numbered or mis-ordered video |
| `courses.json` | The validated import data |
| `reconciliation.md` | Per-course reconciliation and the full lesson map (Adilo id and original title for every lesson) |
| `import.sql` | The database import: backup first, then idempotent upserts |
| `import.compact.sql` | The same import in a smaller file (generated by `compact.py` from `courses.json`). It gives exactly the same rows as `import.sql`; use it if the SQL Editor struggles with the larger file |
| `thumbnails/render.cjs` | Generates the branded 1280×720 thumbnails for the new courses → `public/images/courses/<slug>.jpg` |

## What the import does

- **Backs up** `courses`, `course_sections`, `lessons` and `categories` into the schema `backup_20261122`.
- **Adds three optional columns** (nothing else in the schema changes):
  - `course_sections.description`, the section overview;
  - `courses.seo_title` and `courses.seo_description`, the search-result title and description.
- **Adds two categories:** Career Development and Communication Skills.
- **Updates the 2 existing courses in place:**
  - Interview course (`course-c3f139cd`): content, sections and readable slug change. Its lesson ids are unchanged, so the 3 enrolled students' progress stays.
  - Creative Writing course (`course-3bda155b`): the same updates, plus its 28 missing Adilo videos are added.
  - Each course's draft or published state is kept.
- **Creates 8 new courses as drafts** (`course-adilo-<project>`) with all their lessons.
- **Does not touch** enrollments, payments, reviews or lesson progress, and deletes nothing.
- **Safe to run more than once:** every row has a fixed id and is updated, never duplicated. This was tested twice on a local copy of the tables.

## Apply order

1. **Deploy the website code first**: push to GitHub as usual. The new code works whether or not the import has run: optional columns are read only when present, and old course addresses keep working.
2. **Run the import:** open Supabase → SQL Editor → New query, paste the whole of `import.compact.sql` (or `import.sql`), and click Run. It runs as one transaction: if anything fails, nothing changes.
3. **Thumbnails:**
   - The 8 new courses use `https://edufyacademy.com/images/courses/<slug>.jpg`, which go live with step 1.
   - For the 2 existing designed thumbnails, the logo is added top-right in the browser, uploaded through the admin image upload, and `thumbnail_url` updated.
4. **Review each course** in Admin → Courses, then **publish** it.

   Publishing queues the automatic "New Course Available!" push to students. That's existing behaviour, controlled in Admin → Push notifications.
5. **Redeploy the website after publishing**, so the sitemap, the prerendered course pages and the 301 redirects from `/courses/<id>` to `/courses/<slug>` include the published courses.
6. **In Google Search Console:** resubmit `sitemap.xml` and request indexing for the new course addresses.

## Rollback

The backup schema holds the tables exactly as they were before the import. Use this only **before** any new course has been published or sold, because removing a course also removes data that belongs to it:

```sql
begin;
delete from public.lessons where id like 'les-adilo-%';
delete from public.course_sections where id like 'sec-adilo-%';
delete from public.courses where id like 'course-adilo-%';
update public.courses c set slug = b.slug, title = b.title, subtitle = b.subtitle, description = b.description, category = b.category,
  category_slug = b.category_slug, level = b.level, learning_outcomes = b.learning_outcomes, prerequisites = b.prerequisites,
  target_audience = b.target_audience, total_lessons = b.total_lessons, duration_hours = b.duration_hours
  from backup_20261122.courses b where b.id = c.id;
update public.course_sections s set title = b.title, section_order = b.section_order from backup_20261122.course_sections b where b.id = s.id;
update public.lessons l set section_id = b.section_id, title = b.title, lesson_order = b.lesson_order, is_free_preview = b.is_free_preview,
  duration_minutes = b.duration_minutes from backup_20261122.lessons b where b.id = l.id;
commit;
```

The two new categories and the optional columns can stay; they're unused when empty.
